# 《餐这儿》隐私政策（网页 / H5 版）

| 项目 | 内容 |
|------|------|
| 应用名称 | 餐这儿 |
| 应用类型 | 纯前端单机餐饮经营休闲游戏 |
| 适用平台 | 桌面及移动设备浏览器（直接打开 `index.html` 或访问托管网页） |
| 政策版本 | V1.0 |
| 生效日期 | 2026 年 10 月 25 日 |

《餐这儿》网页版（下称"本游戏"）是一款纯前端、零后端依赖的单机经营小游戏。我们非常重视你的个人信息与隐私。本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》及国家网信办关于收集使用个人信息的相关规定编写，向你说明本游戏处理信息的全部情况。

请你务必审慎阅读、充分理解本政策各条款。**你继续游玩本游戏，即表示你已阅读并同意本政策。** 如果你不同意本政策，请关闭页面并清除浏览器数据，这不会对你产生任何不利影响。

## 一、总体原则：纯前端运行，零后端，数据不出设备

本游戏是**纯单机网页游戏**：

- 全部游戏逻辑在你的浏览器本地运行，不接入任何游戏服务器；
- 游戏代码不包含向任何服务器上传数据的网络请求，游玩过程中不联网、不发送任何数据；
- 你的昵称、游戏进度等数据**仅保存在你所用浏览器（本机）的本地存储中**；
- 本游戏无账号系统、无第三方登录、无支付、无广告、无推送、无统计脚本、无 Cookie 追踪。

## 二、我们存储的信息及用途

以下信息**全部保存在浏览器的 localStorage 中，仅存在于本机**，不会上传到任何服务器：

| 信息 | 内容 | 用途 | 保存位置 |
|------|------|------|----------|
| 玩家昵称 | 你自拟的昵称（2–12 个字符，仅用于游戏内称呼和区分不同存档） | 游戏内显示、存档标识 | 浏览器 localStorage |
| 游戏进度存档 | 资金、店铺、菜品、员工、成就等游戏内数据 | 保存/恢复游戏进度；同一浏览器支持多份存档（以昵称区分，通过「加载存档」切换） | 浏览器 localStorage |
| 新手教程完成标记 | 是否已完成新手教程 | 决定是否再次显示新手引导 | 浏览器 localStorage |

**本游戏不收集**：手机号码、位置信息、通讯录、短信、相机、麦克风、剪贴板、身份证件、支付信息、浏览器历史等任何个人信息；不使用 Cookie，不进行任何跨站追踪。

## 三、浏览器权限：无

本游戏**不向你申请任何浏览器敏感权限**（不请求通知、位置、麦克风、摄像头、蓝牙等权限）。游戏仅使用浏览器的基础能力：localStorage 保存进度、文件下载/文件选择器用于存档导出导入、Web Share API 用于分享（均仅在你主动点击相应按钮时调用，且由浏览器系统界面呈现）。

## 四、存档导出、导入与分享

1. **导出存档**：仅在你主动点击「导出存档」时，游戏把你的全部存档（含昵称与游戏进度）生成为一个名为「餐这儿存档.json」的文件，通过浏览器「另存为」/下载保存到你选择的位置。
2. **导入存档**：仅在你主动点击「导入存档」并确认后进行，通过浏览器文件选择器选取此前导出的存档文件（兼容读取旧版《餐志儿》的存档文件）。**导入会覆盖本浏览器内的全部存档，执行前游戏会先要求你确认。**
3. **分享存档**：仅在你主动点击「分享存档」时，游戏调用浏览器 Web Share API（如浏览器支持）拉起系统分享面板，把存档文件分享给你指定的对象；不支持时退回为下载。是否分享、分享给谁，完全由你决定并操作；游戏不经手该过程，也不获知你分享给了谁。
4. 导出的存档文件由你自行保管。该文件包含你的游戏昵称与游戏进度，不包含其他任何信息，请在传输、转发时自行注意。

## 五、第三方说明

1. **开源渲染库 three.js（r147）与 Feather Icons**：作为本游戏内置的图形渲染与图标库随页面分发，仅在浏览器本地运行，不联网、不采集任何数据（许可与版权声明见仓库 `THIRD-PARTY-NOTICES.md`）。
2. 除上述开源库外，本游戏**未集成任何第三方 SDK、统计脚本、广告脚本或追踪像素**，也未与任何第三方共享信息（本游戏无服务器，无数据可共享）。
3. 如你通过第三方网站/平台访问本游戏（例如他人托管的镜像页），该网站自身可能按其隐私政策记录访问日志等常规运维信息，此类信息由该网站处理，与本游戏无关，请以该网站自身的隐私政策为准。

## 六、信息的存储与销毁

- 上述数据仅保存在你所用浏览器、所用设备上；换浏览器或换设备后互不可见；
- 我们没有服务器，因此**无法访问你设备上的任何数据**；
- **删除方式**：在浏览器设置中清除该站点的浏览数据（或使用浏览器的无痕/隐私模式游玩），即可删除全部本地数据。删除后数据不可恢复。

## 七、未成年人保护

本游戏为休闲单机网页游戏，未针对未成年人设计专门功能，不收集年龄等任何个人信息。未成年人使用本游戏的，其游戏数据同样仅保存在本地浏览器中。家长或监护人如需删除未成年人的游戏数据，清除浏览器站点数据即可。

## 八、你的权利

由于本游戏全部数据保存在你的浏览器本地，你可以随时自主行使以下权利，无需向我们申请：

1. **查询 / 复制 / 导出**：使用游戏内「导出存档」功能，获得你的全部数据副本（也可在浏览器开发者工具的 localStorage 中直接查看）；
2. **更正**：使用游戏内「修改昵称」功能更改昵称，或删除旧存档后重新开始；
3. **删除**：清除浏览器中该站点的本地数据；
4. **撤回同意**：关闭页面并清除浏览器数据，即视为撤回你对本政策的同意。

如你对上述方式有疑问，或需要我们协助，请按第十节的联系方式与我们联系。
